# ระบบลงเวลาเข้างานด้วยการสแกนใบหน้า

เว็บแอปลงเวลาเข้า-ออกงานด้วยใบหน้า สำหรับโรงงาน นับวันที่มาทำงานจริง, OT เที่ยง และ OT เย็น
เก็บข้อมูลใน [Supabase](https://supabase.com) และ deploy ด้วย GitHub Pages

## ความสามารถ
- สแกนหน้าลงเวลาเข้า/ออก (face-api.js ทำงานในเบราว์เซอร์): ระบบประกาศชื่อด้วยเสียงก่อน แล้วให้หันหน้ายืนยัน · มีปุ่ม "ไม่ใช่ฉัน" · ไม่เดาถ้าหน้าคล้ายคนอื่น
- ช่วงพักเที่ยง สแกนหน้าเพื่อลงชื่อ OT เที่ยง · OT เย็นคำนวณจากเวลาสแกนออก
- นับเฉพาะวันที่มาทำงานจริง พนักงานสลับกันหยุดได้โดยไม่นับขาด
- ครึ่งวันนับ 0.5 วัน: เข้างานช่วงบ่าย หรือทำงานไม่ถึง 5 ชม. (ปรับได้ในตั้งค่า)
- ปฏิทินวันทำงาน / วันหยุดโรงงาน
- ขอลาที่เครื่องสแกน (ยืนยันด้วยใบหน้า) → HR อนุมัติในเมนู การลา · นับสิทธิ์ลาต่อปี (ป่วย/กิจ/พักร้อน) · วันลาแสดงในรายงานและ CSV
- ใส่ค่าแรงรายวันหลังบ้าน (เห็นเฉพาะ HR) → คำนวณค่าแรงปกติ, ทำงานวันหยุด 2x, OT 1.5x / วันหยุด 3x, วันลาที่อนุมัติ, วันหยุดนักขัตฤกษ์, หักประกันสังคม
- รายงานรายวัน รายเดือน · ส่งออก Excel ทำเงินเดือน (สรุป + ตารางเวลารายวัน + รายละเอียด) และ CSV
- ถ้าอินเทอร์เน็ตหลุด การสแกนเก็บไว้ในเครื่องแล้วส่งขึ้นระบบอัตโนมัติ
- อัปเดตสดระหว่างเครื่องสแกนหน้างานกับหน้าจอ HR
- แจ้งเตือน LINE ให้ HR (แชทส่วนตัวหรือกลุ่ม): คำขอลาใหม่ทันที + สรุปประจำวัน 21:00 · ตั้งค่าได้ในแอป (ตั้งค่า → แจ้งเตือน LINE) ผ่าน Edge Function `att-line`

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (HTML + CSS + JS) |
| `ai-worker.js` | AI จดจำใบหน้า ทำงานเบื้องหลัง (Web Worker) ให้หน้าจอกดได้ตลอด |
| `manifest.webmanifest`, `sw.js`, `icons/` | ทำให้ติดตั้งเป็นแอปได้ (PWA) และเปิดได้แม้เน็ตไม่ดี |
| `tools/make-icons.ps1` | สร้างไอคอนแอปใหม่ |
| `serve.js` | เซิร์ฟเวอร์สำหรับทดสอบในเครื่อง: `node serve.js` แล้วเปิด http://localhost:5173 |
| `supabase/schema.sql` | โครงสร้างฐานข้อมูลและกฎความปลอดภัย (RLS) |

## ติดตั้งเป็นแอปในเครื่อง
- **Android / Chrome / Edge บนคอม:** เปิดเว็บแล้วกดปุ่ม **ติดตั้งแอป** มุมขวาบน (หรือเมนู ⋮ → ติดตั้งแอป / Add to Home screen)
- **iPad / iPhone (Safari):** กดปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
- แอปที่ติดตั้งแล้วเปิดเต็มจอเหมือนแอปทั่วไป และอัปเดตเองเมื่อมีการ deploy ใหม่

## ความปลอดภัยของข้อมูล
- ข้อมูลใบหน้าเป็นข้อมูลชีวภาพ (PDPA มาตรา 26) ต้องได้รับความยินยอมจากพนักงานก่อนลงทะเบียน
- ทุกตารางเปิด Row Level Security: อ่าน/เขียนได้เฉพาะผู้ใช้ที่ล็อกอินและอยู่ในตาราง `att_staff`
- คีย์ใน `index.html` เป็น publishable key ของ Supabase ซึ่งออกแบบมาให้ใช้ในเบราว์เซอร์ได้ ไม่ใช่ความลับ

## บัญชีผู้ใช้ 2 ประเภท
| ประเภท | ทำอะไรได้ |
|---|---|
| **HR** | ทุกเมนู: ลงทะเบียนพนักงาน, รายงาน, ปฏิทิน, ตั้งค่า, จัดการบัญชี |
| **เครื่องสแกนอย่างเดียว** | เห็นแค่หน้าสแกน ใช้กับแท็บเล็ตหน้างาน เห็นข้อมูลลงเวลาย้อนหลังแค่ 3 วัน แก้หรือลบอะไรไม่ได้ |

สิทธิ์ถูกบังคับที่ฐานข้อมูล (RLS) ไม่ใช่แค่ซ่อนเมนู

### เพิ่ม / แก้บัญชี
HR เข้า **ตั้งค่า → ผู้ใช้งานและรหัสผ่าน** แล้วเพิ่มบัญชีได้เลย ใช้ชื่อผู้ใช้ภาษาอังกฤษ (เช่น `scan1`) หรืออีเมลก็ได้
เปลี่ยนรหัสผ่าน เปลี่ยนประเภท และลบสิทธิ์ได้จากหน้าเดียวกัน (ทำงานผ่าน Edge Function `att-admin` ใน `supabase/functions/`)
