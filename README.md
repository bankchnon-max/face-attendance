# ระบบลงเวลาเข้างานด้วยการสแกนใบหน้า

เว็บแอปลงเวลาเข้า-ออกงานด้วยใบหน้า สำหรับโรงงาน นับวันที่มาทำงานจริง, OT เที่ยง และ OT เย็น
เก็บข้อมูลใน [Supabase](https://supabase.com) และ deploy ด้วย GitHub Pages

## ความสามารถ
- สแกนหน้าลงเวลาเข้า/ออก (face-api.js ทำงานในเบราว์เซอร์) พร้อมตรวจการกระพริบตากันการใช้รูปถ่าย
- ช่วงพักเที่ยง สแกนหน้าเพื่อลงชื่อ OT เที่ยง · OT เย็นคำนวณจากเวลาสแกนออก
- นับเฉพาะวันที่มาทำงานจริง พนักงานสลับกันหยุดได้โดยไม่นับขาด
- ปฏิทินวันทำงาน / วันหยุดโรงงาน
- รายงานรายวัน รายเดือน ส่งออก CSV สำหรับทำเงินเดือน
- ถ้าอินเทอร์เน็ตหลุด การสแกนเก็บไว้ในเครื่องแล้วส่งขึ้นระบบอัตโนมัติ
- อัปเดตสดระหว่างเครื่องสแกนหน้างานกับหน้าจอ HR

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอปทั้งหมด (HTML + CSS + JS) |
| `serve.js` | เซิร์ฟเวอร์สำหรับทดสอบในเครื่อง: `node serve.js` แล้วเปิด http://localhost:5173 |
| `supabase/schema.sql` | โครงสร้างฐานข้อมูลและกฎความปลอดภัย (RLS) |

## ความปลอดภัยของข้อมูล
- ข้อมูลใบหน้าเป็นข้อมูลชีวภาพ (PDPA มาตรา 26) ต้องได้รับความยินยอมจากพนักงานก่อนลงทะเบียน
- ทุกตารางเปิด Row Level Security: อ่าน/เขียนได้เฉพาะผู้ใช้ที่ล็อกอินและอยู่ในตาราง `att_staff`
- คีย์ใน `index.html` เป็น publishable key ของ Supabase ซึ่งออกแบบมาให้ใช้ในเบราว์เซอร์ได้ ไม่ใช่ความลับ

## เพิ่มผู้ใช้งาน
1. Supabase Dashboard → Authentication → Users → **Add user** (ใส่อีเมลและรหัสผ่าน, ติ๊ก Auto Confirm)
2. SQL Editor รันคำสั่ง:
   ```sql
   insert into public.att_staff (user_id, email)
   select id, email from auth.users where email = 'อีเมลของผู้ใช้';
   ```
3. ให้เครื่องสแกนหน้างานล็อกอินด้วยบัญชีของตัวเอง ระบบจะจำการล็อกอินไว้
